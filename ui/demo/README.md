# 界面演示

`index.html` 是一个单文件的界面原型，用来演示和讨论产品形态，**不连接后端，数据都是示例**（取自 fifo 和 src 两个样例的运行结果）。

打开方式：直接双击 `index.html`，或者用浏览器打开。不需要网络，也不需要安装任何东西。

| 页面 | 对应阶段 | 可以演示的操作 |
|---|---|---|
| 概览 | 全流程 | 关键指标、流水线状态、待处理事项 |
| 流水线 | N0–N10 | 点「运行流水线」看逐阶段运行和日志；点阶段看详情 |
| 结构性检查 | N2b | 候选缺陷排在最前；查看反例波形；标记缺陷 / 缺环境假设 / 误报 |
| 环境假设 | N3a | 接受或拒绝假设；OPEN 列表；env_missing 归类 |
| 断言审阅 | N4、N5、N10 | 按来源、状态、层级筛选；证据链；交付版 / 验证版 / 反例；接受、拒绝（选原因）、待定；批量接受 |
| 覆盖 | N7 | 四项覆盖指标、闭环轮次、覆盖缺口 |
| 交付与 CI | N10 | 交付包文件、CI 配置片段、变更影响 |
| 配置 | N0、LLM 合规、FTO | YAML、LLM 模式、FTO 敏感开关、引擎 |

N6–N10 还没有实现，相应页面上的数字是按规格设想的占位值。
