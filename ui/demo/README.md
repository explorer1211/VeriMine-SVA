# 界面演示

`index.html` 是验证工作台的界面原型，用于演示和讨论产品形态。**不连接后端，所有数据都是示例**（以 fifo、hs_rx、src、ctl 几个样例为原型，拼成一个虚构的 `demo_top`）。

打开方式：直接双击 `index.html`，或在浏览器中打开。不需要网络。图标来自本地的 `assets/lucide.min.js`（ISC 许可，见 `assets/LUCIDE-LICENSE`）。

视觉方向参考 EDA 调试工具：深色顶栏，绿色作强调色，提供浅色 / 深色两套主题（右上角切换，或在地址后加 `?theme=dark`）。反例调试以波形为主工作面。所有状态都用"图标 + 文字"表示，不只靠颜色区分。

| 工作区 | 对应阶段 | 可以演示的操作 |
|---|---|---|
| 运行总览 | N0–N10 | 输入哈希（悬停可看定义）；点阶段条看各阶段结果；点结果条跳到对应断言；「重新运行」打开确认抽屉，显示哪些阶段复用、哪些重跑，并模拟逐阶段运行 |
| 反例调试 | N7、N8 | 结果列表与状态筛选；波形支持 A/B 游标、Shift + 点击放置 B、方向键逐拍移动、缩放、跳到失败点、跳到选中信号的前后跳变、点概览条定位；源代码、证据链、逻辑锥三个页签，点信号名可跳回波形 |
| 全部断言 | N4–N7 | 按总状态、来源、层级、是否依赖假设筛选；仿真 / 形式 / cover 三项分列；排序；导出 CSV |
| 审阅队列 | N10 | 按来源 / 类别 / 模块分组；接受、拒绝（必须选原因）、待定；批量操作前确认数量；决定保存在浏览器本地 |
| 设计结构 | N1、N2、N2b | 实例状态（OK、有警告、BLOCKED、多时钟未支持）；每个实例上的断言和结构性检查 |
| 环境假设 | N3、N3a | 轨迹来源与 S_mine / S_val 划分；假设的五种状态；接受 / 拒绝；OPEN 提示 |
| 覆盖与闭环 | N7 | 四项指标与上一轮对比；COI 覆盖随轮次变化；覆盖缺口 |
| 版本差异 | 研究线 R | 网表哈希 → 有界等价检查 → 差异模式；页面固定显示"部分清单"；单独标出 X 语义（不定值被收窄）的情况 |
| 配置与引擎 | N0a、LLM 合规、FTO | YAML 中推断值与未决项分色标注；「加入一个未决项」后运行按钮被禁用；LLM 模式切换（境外云端默认拒绝）；FTO 开关；引擎状态 |

N6–N10 还没有实现。界面上这几个阶段的结果是按规格设想的示例，运行总览中选中这些阶段时会注明。
